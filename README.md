# DEFY Plan Builder

An interactive 2027 business plan builder for DEFY members and guests. Visitors answer a few questions about their income goal, weekly hours and work, pick an offer, choose how they attract, nurture and convert, and get a plan they can email to themselves, download or copy, with a link to book a DEFY call.

Hosted with GitHub Pages from the `main` branch. Lead capture posts each finished plan to a private Google Apps Script web app, which saves it to a Google Sheet and emails Bunny. Set its URL in `CONFIG.endpoint` near the top of the script in `index.html`. No lead data is stored in this repository.
